# WebAIHarnessRoom

归集 WebAI Harness 的组织门厅。Harness 以独立仓库存在，本组织负责提供稳定入口和可发现的索引。

## 设计理念

WebAIHarnessRoom 归集与 Web AI 相关的 Harness，服务于一个目标：让人类更高效地驾驭 Web AI，同时更清楚地知道它做了什么。

- **人机交互优先**：Web AI 的优势在网页端的人机交互。Harness 应放大这个优势，而不是把 Web AI 降格成纯 API 调用。
- **高效且透明**：驾驭效率与过程可见并重。人类应能看到关键动作，并在需要时确认或干预。
- **免费是入口，不是目的**：很多 Web AI 当前可免费使用，这降低了尝试门槛；但免费只是暂时的。项目核心不是“为了免费而用 Harness”，而是探索 Harness 与 Web AI 的结合方式。
- **不以 API 替代 Web AI**：不把“使用 Harness”变成“换一种方式调 API”。Harness 应围绕 Web AI 的网页交互能力设计。
- **Harness 自治，Room 归集**：Harness 以独立仓库存在，组织层暂不设统一标准，Room 负责索引、入口和状态呈现。
- **面向 WebAIAgent**：当前先建 Room；后续 WebAIAgent 将使 Web AI 与 Harness 的连接更自然。

## 边界

尊重 Web AI 的正常使用边界。Room 的价值是帮助人类在边界内更高效地利用 Web AI，而不是突破边界或大规模滥用免费能力。

## 原则

- Harness 自治，组织层不定义准入门槛。
- 归集靠索引声明存在，状态靠 Project 呈现。
- 当前阶段不设统一标准，让模式从实践中长出来。
